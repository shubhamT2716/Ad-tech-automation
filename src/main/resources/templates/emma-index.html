Emma - COP Test Automation Tool

Rule based and extensible test automation tool built using Spring Boot and Playwright. You can write test cases in YAML using web interface and submit for execution.

Features

  • User editable test cases
  • Scheduling and Batching
  • Parallel Execution
  • Cross Browser Testing (Edge, Chrome, Firefox, Webkit/Safari)

Feel free to explore the following test suites. You can add / modify the YAML rules.
