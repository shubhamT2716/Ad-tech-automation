Emma - COP Test Automation Tool

Rule based and extensible test automation tool built using Spring Boot and Playwright. You can write test cases in YAML using the web interface and submit them for execution.

Features

User Editable Test Cases

Easily edit and manage your test cases using our web interface.

Scheduling and Batching

Schedule and batch your tests to run at your convenience.

Parallel Execution

Run tests in parallel to save time and increase efficiency.

Cross Browser Testing

Test across multiple browsers including Edge, Chrome, Firefox, and Webkit/Safari.
